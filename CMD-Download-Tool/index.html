Default: English (en). Use a language code such as fr, de, es, or ja. Only selected subtitle languages will be requested.

Language selection uses yt-dlp audio metadata; availability is not checked in advance. With fallback off, a missing matching track causes format selection to fail. Subtitle language is separate.

ADVANCED // HIDDEN OPTIONS

Works with yt-dlp supported sites, not only YouTube. Formats and metadata vary by site. GIF / MOV / AVI and other requested conversions require FFmpeg. Conversion can re-encode media and is not guaranteed for every source. Clip times are approximate and may need keyframe adjustment.

yt-dlp supports many websites. Actual compatibility depends on the URL and your installed yt-dlp version.
